# materiale simulation
Krav
Skal have pygame og python installeret

Brugerinteraktion
Brugeren integrerer med programmet med tastatur og mus.
•	Venstre museknap kan placere og fjerne materialer i gitteret.
•	Brugeren kan skifte mellem materialerne med tastaturet (s = sand, r = rock, e = eraser)
•	Simuleringen kan nulstilles ved at trykke på spacebaren.

Når brugeren klikker på vinduet, vælges det gitterfelt som musens position er placeret i.
Derudover kan man også ændre på en række variabler i koden
•	frameraten, 
•	gitterstørrelse
•	vinduestørrelse
•	penselstørrelse
